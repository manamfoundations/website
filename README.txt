FREE DEPLOYMENT:
Recommended: GitHub Pages or Cloudflare Pages.
The site contains no paid libraries or backend.

BEFORE PUBLISHING:
1. Replace the placeholder logo.svg with the final Manam Foundations logo if desired.
2. Replace contact@manamfoundations.org with the official email if different.
3. Add your official phone number, address, Instagram/Facebook links and donation details when ready.
4. Replace the CSS illustration on the home page with approved foundation photos if available.

The contact form currently opens the visitor's email app using mailto; a server-side form service can be added later.
